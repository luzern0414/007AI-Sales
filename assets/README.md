# assets：素材目录约定

状态：文档阶段。当前没有图片、界面原型、图标、录音样例或生成代码。
本目录未来可存已授权的产品图标、手机页面参考、合成 Demo 截图和设计资源；客户原音不在公开素材目录保存。

## 保存规则

按用途与版本建立子目录；文件名建议包含用途、页面、日期和版本，避免真实客户姓名、电话、项目机密或访问 token。
每个外部素材登记来源 URL、作者、许可/购买授权、使用范围及修改记录，不能用“网上找到”替代授权。
产品截图优先使用合成数据，遮盖真实称呼、邮箱、电话、金额、录音 URL、域内管理入口和分享 token。
截图、缩略图和视频均按客户派生资料处理；组织私有案例素材不自动转公共广场。
导出图片时保留目标手机尺寸与主题版本，截图不作为实际 CRUD 或持久化通过的证据。
删除案例/项目后需立即撤销素材访问，物理缓存清理遵循[保留和删除政策](../config/settings-catalog.md)。

未来设计产物应对应[功能方案](../docs/product/functional-spec.md)的四入口及异常状态，并明确标注方案草案与合成内容。
