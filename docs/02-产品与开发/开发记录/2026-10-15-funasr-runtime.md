# 本地 FunASR 实时接入

沿用已确定的手机录音独立归档、后端私有2pass识别架构。继续采用本机CPU，模型下载本地，录音不外传。离线文件识别已验证，仍需真实流式模型及网页闭环。

## 设计与顺序

1. 修复已确认的停止协议问题：官方运行时仅在停止消息显式含`is_end:true`时返回结束确认。先用协议用例重现，再修改后端。
2. 部署独立环境模型服务。使用FunASR SDK进行流式Paraformer初稿、FSMN-VAD断句及离线Paraformer+标点修正。与平台进程隔离；仅监听127.0.0.1，限制一路会议、队列大小、输入帧、空闲时间及语音段长度，避免长期会议无界积累。模型加载完成才监听。
3. 固定模型文件及SHA-256。增加流式模型，其余复用已核验模型；安装锁文件记录运行版本。
4. 停止时依次冲刷VAD、流式缓存及离线尾句，确认成功后才发结束标记。异常明确报错，平台原音独立保存。服务不自动调用收费接口。
5. 运行协议、边界、尾音及故障检查；以授权录音片段通过真实服务、平台WebSocket、数据库和网页显示验证。隔离测试库，不导入真实开发库。

## 验收证据

保留模型下载清单、服务运行日志、实际转写事件、数据库回读及浏览器操作结果。协议工装不计为识别效果。单段样本不能证明长会议、手机后台、生产并发、识别准确率全部达标。尚未完成的断网补识别及手机HTTPS真机检查持续记录。
