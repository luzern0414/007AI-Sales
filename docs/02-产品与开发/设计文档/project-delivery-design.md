# 手机 Web 销售与项目交付平台

版本：V3.0；2026-10-15。当前业务基线。V3 是文档修订，不是项目分期。代码及测试状态单独见开发记录。

## 产品边界

平台以项目为单位串联洽谈、需求、方案、合同、实施、测试、上线、验收与维护。流程节点可按实际合同调整，不把流程步骤写成一期二期。会议录音、纪要 MD/PDF、售前方案、需求清单及甲方资料权限规则清单继续保留。

下表规定四个一级入口。

| 入口 | 手机端主要任务 | 数据归属 |
|---|---|---|
| 首页 | 开始/继续现场会议，实时文字、速记、保存状态，最近项目 | 会议必须关联项目；可先新建项目 |
| 项目管理 | 找项目，查完整时间线、文件、会议、任务、问题、变更、交付证据 | 所有活动有项目、来源、操作者与版本 |
| 产品库 | 向客户展示已落地产品、已批准介绍 PDF 和脱敏系统 | 内部资料、成本与客户数据不进入展示响应 |
| 工作台 | 跨项目待办、临期/逾期、风险、进度、最新变化、资料更新；生成/编辑方案清单 | 读取相同项目事实，不建立另一份进度 |

## 项目链路与交付关口

下表说明常用流程。阶段变更记录前后状态与依据；跳过需说明理由，退回保留历史。

| 环节 | 输入与操作 | 进入下一环节的证据 |
|---|---|---|
| 洽谈 | 客户信息、会议、现状、痛点、决策人与目标 | 已记录目标、需求与待确认项 |
| 需求确认 | 全量会议抽取、资料核实、范围与排除项 | 经授权人确认的需求基线及验收标准 |
| 方案与商务 | 产品匹配、方案、演示、报价、合同 | 方案/合同有效版本、交付范围和前提 |
| 实施准备 | 里程碑、负责人、任务、依赖、甲方资料权限规则清单 | 排期基线和所需输入可用；缺失形成阻塞 |
| 实施 | 开发/配置/集成、变更、问题、迭代证据 | 可验收版本、测试记录、未解决问题清单 |
| 联调与试用 | 功能、权限、异常、数据与真实页面验证 | 试用结果和问题复测证据 |
| 上线与验收 | 部署、备份恢复、培训、配置与交付材料 | 授权验收人确认、交付物齐备、阻断问题关闭或获批例外 |
| 维护与归档 | 运维交接、遗留事项、保修/维护、复盘 | 服务责任与截止时间明确；归档只读，可受控重开 |

项目状态与阶段分开：进行中、暂停、已交付、已归档、已取消。任务状态：待办、进行中、受阻、待验收、已完成、已取消。完成要有证据；AI 不自行批准验收、合同、范围或承诺日期。阶段门规则由项目负责人确认，不凭模板日期推断业务承诺。

## 时间线、文件与追溯

文件存不可变原件、SHA256、MIME、大小、上传人、录入时间、来源发生时间、版本链、可见范围、解析状态及引用位置。支持实际会议录音、PDF、DOCX、XLSX、图片、文本及其他合法附件；不支持解析的附件仍可归档下载，不能伪称已阅读。限制单文件和总容量，流式写入、类型核验、恶意文件隔离与清理。

下表规定三种视图，排序由程序完成，AI 只提供分类与关联候选。

| 视图 | 排序与行为 |
|---|---|
| 最新文件 | 默认上传/修订时间倒序，稳定 ID 为同时间排序键；原始文件日期另列，不用文件名猜日期 |
| 项目时间线 | 默认发生时间倒序，可切正序；补录显示发生/录入两时间，未知发生时间标未确定 |
| 交付链路 | 需求 → 方案章节 → 任务 → 版本/测试 → 问题修复 → 验收 → 交付物；缺失显示待补 |

事件包含来源文件/页码/会议片段、可信状态、确认者、关联需求/任务/问题、发生/录入时间、版本及替代关系。修订使用新事件并指向旧事件，不静默覆盖。最新上传不天然推翻已确认合同。矛盾进入待确认；全文检索受项目权限硬过滤。选择日期可回看“当时已知信息”，与按发生时间回看区分。

AI 入库流程：上传成功 → 安全检查/解析 → 全量分段覆盖 → 提取事件、决定、需求、任务、问题 → 去重与候选关联 → 形成待确认记录 → 授权人确认关键变更 → 更新事实投影和提醒。低风险进展摘要可按项目规则自动发布，必须有来源、标 AI 整理、可撤回；日期/责任/范围/完成结论不能自动变为已确认承诺。

## 工作台与真实进度

工作台按项目负责人/执行者可见范围汇总：今日待办、临期、逾期、受阻、待确认、资料过期、最新进展。点击直达项目相应任务或来源。摘要显示更新时间及依据；无输入写“未更新”，不填随机百分比。

下表规定计算口径与边界。

| 项目 | 规则 |
|---|---|
| 完成比例 | 已完成且验收有效的非取消任务权重 / 全部有效范围任务权重；默认同权重，采用权重时保存基线与变更，0 任务显示未设计划 |
| 开发进度 | 任务状态/关联开发文档版本/测试与交付证据；代码提交不等于测试通过或交付完成 |
| 延期 | 程序比较截止日、工作日历与当前时间；依赖未完成、阻断问题、输入缺失分别形成风险，缺日期不猜日期 |
| 风险提醒 | 临期阈值为可配置初稿，站内提醒去重、确认、指派、处理、关闭/重开；不保证绝不延期 |
| 实时 | 业务事务写 outbox；服务端事件刷新投影与页面，断线后按游标补取；显示最后同步时间 |
| 外部文档 | 逐来源授权，只读同步、版本/hash/etag/游标与撤权；Webhook 验签防重放 + 增量轮询兜底 + 定期全量核对；失败显示同步失败，不伪装最新 |
| 连接边界 | 本地路径不会自动被手机或服务器读取；支持上传与明确授权的连接器；初版未接来源必须标未连接 |

外部来源先做通用连接契约，针对实际使用的 Git/文档服务再实现适配，不假设已连接任何账号。平台不自动向客户发信、改外部文档或部署系统。提醒优先站内；外发渠道需另行明确启用和授权。

## 产品展示与内部依据

产品保留内部资料/能力核实，以及面客发布两个视图。发布版本包含产品简介、适用场景、已落地证明、批准的介绍 PDF、脱敏系统入口、功能与限制；停用与撤销即时影响后续请求。展示模式响应由服务端白名单字段组成，禁止仅前端隐藏成本/密钥/项目资料。

脱敏系统使用独立数据与身份、隔离环境、授权演示地址、有效期与访问范围；不能把客户生产系统链接当脱敏版。嵌入受限时在新页打开，不绕过浏览器限制。演示地址只允许明确配置的 HTTPS 域名，阻止脚本 URL 与内网地址；链接可访问不代表已脱敏，必须人工核实后发布。

## 技术扩展

沿用 React/TypeScript/Vite、FastAPI、SQLAlchemy/Alembic、PostgreSQL、私有对象存储及 LangGraph 设计。本机开发可用真实 SQLite 文件，绝不视作 PostgreSQL 上线验证；保持相同业务接口与迁移。录音协议继续采用[实时采集设计](realtime-platform-design.md)的独立保存/ASR路径。项目状态用普通事务服务，确定性排序/进度/风险由程序计算，AI 只处理抽取和文字。

下表规定新增持久对象。

| 对象 | 主要关系与约束 |
|---|---|
| project / membership / baseline | 客户、负责人、阶段、状态、权限、基线修订 |
| file / file_version / source_link | 项目/产品归属不可混淆，版本、hash、存储key、解析/同步状态 |
| event / evidence / revision | 项目内事实与来源，发生/录入时间，幂等键与替代 |
| task / dependency / milestone | 项目、责任、截止/实际时间、完成依据，依赖成环拒绝 |
| issue / change / acceptance | 问题影响/等级/处理证据，变更前后范围及批准记录，验收主体 |
| product / release / demo_access | 内部能力与面客发布版本隔离 |
| notification / sync_cursor / outbox | 去重、投递、重试、读取游标与来源授权 |

API 所有读取/下载/检索按服务端会话与项目成员校验；写操作支持幂等键与乐观锁。客户端不得传用户 ID 获权。附件版本与删除审计遵守保留政策，删除不会靠重放旧事件复活；缓存与索引同步失效。身份、密码和凭证禁止硬编码。开发环境仅绑定本机；移动真机需 HTTPS 与显式网络部署验证。

## 手机体验与开发规范

遵守 `D:\Codes\开发规范.txt`；SHA256：`003E68321989B02FB55E5923DD01FEFABD17CDCA6A01304B80FF6D8FA2383856`。本设计基于交付时源版本，源变化需重新核对。方案与导出继续遵守 `D:\Codes\方案格式规范.txt`。

以 390px 单列设计，验证 320/360/390/430px，再扩展桌面。底部四导航：首页、项目管理、产品库、工作台。正文优先16px，辅助文字不小于14px，触控区至少44px，安全区和键盘不遮挡操作。长表转换逐项详情，不把手机变成缩小的桌面表格。时间线逐页加载，滚动锚点稳定。

界面不出现技术说明、填充文案、冗余副标题和虚构统计；保留必要字段名、可执行按钮、状态、错误和数据来源。无数据提供明确动作，未连接不能显示正常、上传不能冒充解析完成。面客展示不出现内部待办或成本。

## 验收边界

下表为必须执行的验收，不代表当前已实现。

| 链路 | 验证 |
|---|---|
| 项目/任务/事件 | 手机创建编辑、刷新/重登不丢、时间稳定排序、并发冲突、越权拒绝、操作审计 |
| 文件/会议 | 多文件上传中断恢复、重复与版本、内容定位、合法下载、纪要PDF与MD同版本、音频保存与恢复实测 |
| AI | 全量覆盖、来源定位、矛盾/未知不猜、关键更新不越权、重复作业不重复事件、失败可重试 |
| 交付 | 需求到验收证据可追、阻断未关闭不能假验收、日期变更留痕、重开保留历史 |
| 进度与提醒 | 0任务不造比例、取消/权重/时区/依赖计算正确、提醒去重、断线重连补取、过期源可见 |
| 产品 | 面客响应无私密字段、PDF与脱敏发布版本一致、非法地址拒绝、撤销后不能继续鉴权下载 |
| 实机 | iOS Safari/Android Chrome前台麦克风、权限/来电/锁屏边界、弱网、触控、键盘、长文本与PDF检查 |

小程序尚不在本次实现范围；若新增，复用同一后端业务规则并单独真机验证。没有运行的环境、云账号、设备、部署或浏览器测试必须记为未验证。
