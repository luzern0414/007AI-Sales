# 04 排版规范（Word / PDF）

以下数值已固化在 `scripts/docx_kit.py`，正常情况下不需要手动设置；修改规范时同步改代码和本文件。

## 1. 页面

| 项目 | 规范 |
|---|---|
| 纸张 | A4 纵向（21 × 29.7 cm） |
| 页边距 | 上 2.5 cm、下 2.3 cm、左 2.5 cm、右 2.5 cm |
| 页眉 / 页脚距离 | 1.5 cm / 1.4 cm |
| 正文宽度 | 16 cm（表格总宽、图片宽度以此为上限） |
| 分节 | 封面单独一节，无页眉页脚；正文一节，有页眉页脚 |

## 2. 字体字号

| 位置 | 中文字体 | 字号 | 其他 |
|---|---|---|---|
| 封面·项目名 | 黑体 | 小二（18pt） | 居中 |
| 封面·标题 | 黑体 | 一号（26pt） | 居中，分两行：“××智能化 / 实施方案” |
| 封面·副题 | 宋体 | 四号（14pt） | 灰色 #595959，上方细分隔线 |
| 封面·版本、日期 | 宋体 | 四号（14pt） | 居中，页面下半部 |
| 目录标题 | 黑体 | 三号（16pt） | “目　　录”居中 |
| 目录条目 | 一级黑体 / 二级宋体 | 小四（12pt） | 1.2 倍行距，段后 2pt，二级缩进 0.74 cm；目录控制在 1 页 |
| 一级标题 | 黑体（不加粗） | 三号（16pt） | 段前 18pt、段后 10pt，编号“一、” |
| 二级标题 | 黑体 | 四号（14pt） | 段前 12pt、段后 6pt，编号“1.1” |
| 三级标题 | 黑体 | 小四（12pt） | 段前 8pt、段后 4pt，编号“1.”或“1.1.1” |
| 正文 | 宋体 | 小四（12pt） | 1.5 倍行距，首行缩进 2 字符，段前段后 0 |
| 正文强调 | 黑体 | 同正文 | 不加粗、不变色 |
| 表头 | 黑体 | 五号（10.5pt） | 居中 |
| 表格内容 | 宋体 | 五号（10.5pt） | 1.25 倍行距；首列黑体居中 |
| 图题 / 表题 | 黑体 | 五号（10.5pt） | 居中；表题在表上、图题在图下；全文连续编号“表 1  ××”“图 1  ××”（编号后两个空格） |
| 注释 | 宋体 | 五号（10.5pt） | 灰色 #595959，以“注：”开头 |
| 页眉 | 宋体 | 小五（9pt） | 右对齐“甲方项目名 · 方案名”，灰色，下方细线 |
| 页脚 | 宋体 | 小五（9pt） | 居中页码 |
| 西文与数字 | Times New Roman | — | 全部位置 |

全文只允许出现三种字体：**黑体、宋体、Times New Roman**（配图内的微软雅黑不计，属于图片）。
Word 内置标题样式自带“主题字体”属性，必须清除，否则中文标题会混用字体。

## 3. 标题编号

- 一级：一、二、三……；附录写“附录：××”，不编号。
- 二级：1.1、1.2……；三级：1. 2.（功能说明等）。
- 汇报版删除章节后，保留章节编号必须连续。

## 4. 表格

| 项目 | 规范 |
|---|---|
| 宽度 | 总宽 16 cm，居中；列宽在代码中给出，合计必须等于 16 |
| 布局 | 固定列宽（写入表格网格宽度，防止 Word 均分） |
| 外框 | 上下边框 1.5 磅，藏青灰 #3E5C76；左右及内框 0.5 磅，灰 #A6B1BD |
| 表头 | 底色 #E6ECF2，黑体居中，跨页重复 |
| 首列 | 作“名称/项目”列时底色 #F2F5F8，黑体居中 |
| 分组行 | 通栏合并，底色 #F2F5F8，黑体左对齐（如“硬件”“软件”“服务”） |
| 单元格边距 | 上下约 0.1 cm，左右约 0.2 cm |
| 对齐 | 文字左对齐，垂直居中；数量、类型、负责人等短值列居中 |
| 分页 | 行不跨页拆分；表头与第一行数据不分离；表格可跨页续排（表头自动重复），不强制整表同页，避免大片空白；引导语与表格同页 |
| 列宽经验 | 名称列 2.4–3.4 cm；短值列 1.8–3.0 cm；其余给说明列；两列“项目—说明”表用 2.6 + 13.4 |
| 空值 | 写“—”，不留空 |

## 5. 图片

| 项目 | 规范 |
|---|---|
| 宽度 | 15–15.5 cm，居中（结构图可 15 cm） |
| 引导语 | 图前一句话，与图同页 |
| 图题 | 图下，黑体五号居中 |
| 清晰度 | 3 倍渲染（约 300 dpi），PNG |

## 6. 分页与收尾

- 封面、目录各自另起一页。
- 不允许出现空白页；文末用 1 磅高的极小段落收尾（Word 要求表格后必须有段落）。
- 尽量减少空白：表格允许跨页续排；若因“标题+引导语+大图”整体换页留下超过 1/3 页空白，可调整段落顺序或缩小图片到 14 cm。

## 7. 导出

- 用 Word 打开 → 更新目录 → 另存为 PDF（`scripts/export_pdf.ps1` 自动完成）。
- 导出后运行 `scripts/check_pdf.py` 检查字体、空白页、留白、残留占位符，并逐张查看缩略图。
