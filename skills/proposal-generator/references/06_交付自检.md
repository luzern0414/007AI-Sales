# 06 交付自检清单

交给用户前逐项检查。`scripts/check_pdf.py` 能自动查字体、空白页、留白和占位符，其余靠人工核对。

## 内容

- [ ] 甲方名称、项目数据与原始资料一致（对照项目信息卡）
- [ ] 开篇有一句话主线；总体框架图 + 各层说明表（写明详见第几章）
- [ ] 每个问题都有对应的解决思路，并能在后文找到对应章节
- [ ] 每个目标都能检验
- [ ] 同类内容用同一模板表（设备：用途/工作方式/采集数据/安装条件/与系统对接/怎么检验/限制；功能：能做什么/怎么实现/怎么检验/限制）
- [ ] 新增设备或功能已同步到：框架图、建设清单、数据来源、平台功能、权限、业务线、计划、交付、验收、资料清单、待决定事项、风险、能力说明
- [ ] 全文没有“一期 / 二期 / 暂不纳入”
- [ ] 每个功能写明实现方式和限制；做不到的已删除
- [ ] 设备只承诺实际能输出的数据；精度以厂商书面承诺为准；安装条件写清
- [ ] 第三方平台/接口依赖已写成前提并列入风险
- [ ] 未报价的已标“需另行报价 / 按勘察确定”
- [ ] 工期写“预计”，有前提条件表
- [ ] 验收标准都能检验、能做到；AI 文字不承诺准确率
- [ ] 有“系统能力说明”
- [ ] 自拟权重、阈值、口径已标“初稿，待确认”
- [ ] 没有账号密码、未授权的报价或成本价、个人信息
- [ ] 没有残留占位符（`< >`、××、待补充、TODO）

## 格式

- [ ] 只出现 黑体、宋体、Times New Roman
- [ ] 目录已更新、页码正确、目录在 1 页内
- [ ] 表格列宽正常，表头跨页重复，短表不被拆开
- [ ] 图题、表题编号连续；每张图表前有引导语
- [ ] 无空白页；无超过半页的异常留白
- [ ] 汇报版：删除的章节无残留，保留章节编号连续，封面写“汇报版”

## 配图

- [ ] 只用设计令牌中的颜色；强调色只有暖金一种
- [ ] 无折行、截断、重叠
- [ ] 图内文字插入后仍清晰可读
- [ ] 流程图有“系统自动 / 人工确认”图例

## 交付说明（发给用户时写清）

- 文件位置（Word / PDF / 汇报版）
- 自己做的判断和取舍（如删掉了哪些做不到的功能、为什么）
- 需要甲方确认的事项
- 有意没写的内容（如报价）
- 用户确认前不出正式 PDF
